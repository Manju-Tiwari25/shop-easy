# ShopEasy

**Live demo:** https://your-link.vercel.app

A mini online store built with React as a learning project.

## Features

- Product list loaded from the DummyJSON API
- Search, category filter and sorting
- Product detail pages with React Router
- Shopping cart with Context API (add, remove, change quantity)
- Cart saved in localStorage

## Tech

React, Vite, React Router

## Run locally

npm install
npm run dev
